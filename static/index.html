使用教程

日常操作说明
1. 第一次使用
  1. 在服务器电脑运行门店管理系统服务器程序。
  2. 第一次打开时，创建唯一管理员账号。
  3. 管理员登录后进入人员管理，注册员工账号并分配权限。
  4. 手机和电脑连接同一个 Wi-Fi/局域网。
  5. 在浏览器输入服务器显示的 IP 地址和端口。
  6. 如需使用域名，需要在路由器 DNS 或客户端 hosts 中配置解析。
2. 入库和出库
  1. 员工使用自己的账号登录。
  2. 进入日常登记，选择业务类型。
  3. 输入商品 ID、品牌、品名或规格搜索商品。
  4. 选择商品后，商品资料自动填充。
  5. 填写数量和备注，点击提交。
  6. 经办人由当前登录账号自动关联。
3. 商品档案
  1. 进入商品档案，点击新增商品。
  2. 品牌、规格、分类、存放位置和单位都支持搜索已有选项。
  3. 没有匹配选项时，可以直接输入新值。
  4. 保存后，新值会进入后续下拉选项。
4. 盘点
  1. 业务类型选择“盘点调整”。
  2. 填写实际盘点数量，注意这里填写的是实盘数量，不是差异值。
  3. 允许填写 0，系统自动计算盘盈或盘亏。
5. 备份
  1. 系统默认每天自动备份，保留 30 天。
  2. 也可以进入“数据备份”手动备份。
  3. 建议同时下载数据库备份及配套商品图片 ZIP，并另存到其他磁盘。
6. 注意事项
  • 服务器电脑关机时，其他设备无法访问；数据仍保存在服务器硬盘。
  • 不支持断网离线录入，服务器离线时不要重复提交。
  • 新安装默认启用 HTTPS；旧配置如显式关闭 HTTPS，需在设置中启用。手机扫码前需安装并信任本地 CA 证书，不能只忽略浏览器警告。
  • 不要将服务器端口直接映射到公网。
  • 不要将管理员账号和密码分享给普通员工。
