# 维护脚本 / Maintenance scripts

- [verify_project.py](verify_project.py) 检查源码完整性 / Checks the source tree.
- [inspect_database.py](inspect_database.py) 只读检查 SQLite / Inspects SQLite in read-only mode.
- [prepare_release.py](prepare_release.py) 准备 Windows 运行目录 / Prepares the Windows runtime directory.
- [generate_lan_certificate.py](generate_lan_certificate.py) 生成局域网证书 / Generates LAN certificates.
- [run_direct_regression.py](run_direct_regression.py) 运行部分测试作诊断 / Runs a diagnostic subset of tests.
