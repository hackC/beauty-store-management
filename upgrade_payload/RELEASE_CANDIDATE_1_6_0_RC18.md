# 门店管理系统 1.6.0-rc.18

- 临时出勤优先于同日的单日休息、持续休息及每周固定休息。临时出勤仅影响指定日期及出勤时段，其他日期继续按原休息规则执行。
- 休息前预约门槛同时用于班中休息、休息时间块和美容师最后一班结束前，最晚开始时间按营业结束和个人最后一班中较早者计算。23:00 下班且门槛 60 分钟时，22:00 是最晚可开始时间，22:20 不会显示为可约或超时可约。既有预约保留。
- 在真实项目里把项目时长设为 0 分钟。新增预约时单独选中该项目，表单切换为休息模式，只需选择美容师、开始时间和休息时长，备注可选。项目默认等待时间作为初始休息时长，为 0 则使用 30 分钟。休息块阻止重叠预约，不进客户档案或美容师日报，不作为默认服务项目。
- 休息时间块完整落在该美容师的工作时段内，休息结束后恢复预约。删除休息块后，相关可约时段按班次重新计算。

## 从 RC17 增量升级

关闭服务，在增量包解压目录执行以下命令。

```powershell
python .\apply_release_candidate.py --target "D:\RC17源码目录" --check
python .\apply_release_candidate.py --target "D:\RC17源码目录" --apply
```

使用 Windows EXE 时，从新版源码运行 `build_windows.bat`，保留原运行目录的 `data`。全量源码包无业务数据。

回退时使用安装器返回的回退目录。

```powershell
python .\apply_release_candidate.py --target "D:\RC17源码目录" --rollback "D:\回退目录"
```
