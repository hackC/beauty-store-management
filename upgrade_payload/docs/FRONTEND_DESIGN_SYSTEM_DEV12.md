# V1.6.0-dev.12 前端双端设计与实现说明

## 目标
在不改变业务 API、权限语义和数据库结构的前提下，统一门店主页面与每日排班页面的视觉语言和响应式边界。

## 视觉方案
采用规划中的 A「明亮专业」方向：暖白内容底色、深墨绿导航、青绿色主操作、低干扰边框与轻阴影。颜色只用于层级和状态，不用大面积装饰替代业务信息。

## 页面范围
- `static/index.html`：门店管理主页面，商品、库存、采购、经营与设置等业务区。
- `static/index_V2_5_5.html`：每日排班页面，时间轴、预约、员工和相关弹窗。
- 两页共同加载 `app_shell.css`、`dev12_responsive.css` 与 `dev12_ui.js`。

## 响应式行为
- 320/360/390/430 CSS px：手机纵向布局、触控目标至少 44px、输入字号 16px、底部导航安全区留白。
- 641–1100px：保留桌面信息结构，压缩内容边距、网格和工具栏允许换行。
- 桌面：保留侧栏与工作区，头部保持视觉层级。
- 宽表在所属容器内滚动，表头 sticky；已有移动卡片表格继续使用卡片结构，不强行压成 PC 表格。
- 排班时间轴保留内部横向滚动，不让时间轴宽度撑破页面视口。
- 弹窗限制在动态可视高度内，动作区吸底；支持安全区。
- 监听 `visualViewport` 的尺寸变化，键盘弹出、横竖屏和地址栏变化时更新视口 CSS 变量。

## 运行时边界
`dev12_ui.js` 仅负责布局测量、表格滚动区域标记和动态视口变量；不发起业务请求、不重试写操作、不写入 localStorage/IndexedDB，也不改变业务状态。
