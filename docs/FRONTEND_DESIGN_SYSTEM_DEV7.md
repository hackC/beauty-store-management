# PC 与手机双端设计系统规范（dev.7）

视觉方向：A「明亮专业」作为首轮样稿推荐方向——暖白内容区、深墨绿导航、青绿色主操作、明确的状态文字和克制留白。该样稿只用于评审，不替换生产页面。

## 1. 共同设计变量

| 变量 | 初始值/约定 |
|---|---|
| 页面背景 | `#F4F7F5`，降低大面积纯白眩光 |
| 内容表面 | `#FFFFFF` |
| 导航/标题 | `#173431` |
| 主操作 | `#0F766E`；文字与背景对比必须达标 |
| 次要强调 | `#DDF2EB` |
| 警告/风险 | 琥珀/红色，同时必须配文字标签，不仅依赖颜色 |
| 分隔线 | `#E2EAE5` |
| 圆角 | 卡片 14–18px；控件 9–12px |
| 触控目标 | 手机常用操作目标 44–48 CSS px |
| 字体 | 系统无衬线字体；中文优先系统中文字体，不依赖外部字体下载 |

## 2. PC 与手机分别组织

### PC

- 侧栏固定在页面左侧，可收起；内容区宽度受视口约束。
- 页面标题、筛选和主要操作放在同一工具栏层级；常用操作保持可见。
- 首页以待办、异常和当日排班为主，不把每个数字做成独立装饰卡。
- 商品/流水表格只保留关键列，支持详情查看和列配置；列宽固定算法与文本换行策略明确。
- 编辑使用分区表单或受限宽度侧栏；保存区在所属面板底部可见。
- 排班使用员工行与时间轴；人员/时间标记保持定位，避免整张宽表强行压缩。

### 手机

- 采用独立底部高频导航（首页、登记、商品、排班、更多）；低频配置收进“更多”。
- 首页按“待办/异常 → 今日安排 → 常用动作”纵向组织。
- 商品列表改为卡片/键值摘要；不把 PC 全部列缩小塞入手机表格。
- 日常登记采用扫码/搜索优先、单条明细卡片、固定汇总与提交区。
- 排班优先展示当天时间线/单美容师任务，使用日期与人员切换；不默认展示横向超宽全员网格。
- 新增/编辑使用全屏或接近全屏面板，输入分组，保存按钮位于安全区上方。
- 常用动作不依赖悬停；键盘弹出时保留焦点、错误信息和主要提交操作。

## 3. 页面状态

所有页面统一区分：初始加载、刷新、保存中、成功、失败、空数据、无权限、离线/重连、版本冲突。写请求不因网络恢复而自动重放；先重新读取服务端状态，再由用户确认下一步。

保留有效筛选、滚动位置和未提交输入；权限撤销后立即隐藏操作并在服务端拒绝后续请求。

## 4. 滚动与视口硬规范

- 根页面不得出现非必要横向滚动；长内容纵向滚动是允许的。
- 表格表头在所属滚动容器顶部吸顶，离开表格容器边界释放；不得把 sticky 放到错误的祖先滚动上下文。
- 多层分组标题只允许当前层级接替吸顶，避免堆叠遮挡。
- 底部汇总/分页/主要操作在所属区域固定或吸底，必须为其预留内容空间，最后一行可完整滚动到达。
- 弹窗宽高不超过可视区域；标题/关闭/保存保持可达，正文内部滚动。
- 下拉菜单、日期选择器根据边缘空间翻转，不能越出视口。
- 使用 `min-width:0`、`minmax(0,1fr)`、合理换行和内容裁切；不允许用根级 `overflow:hidden` 掩盖横向溢出。
- 适配动态视口、`env(safe-area-inset-*)`、浏览器地址栏和软键盘；不能只依赖固定 `100vh`。
- 固定层级统一定义，导航、表头、底栏、弹窗互不遮挡。

## 5. 设计验收矩阵

| 维度 | 目标尺寸/状态 |
|---|---|
| 手机 | 320×720、360×800、390×844、430×932；竖屏/横屏；软键盘展开 |
| 平板/小窗 | 768px、1024px 宽；浏览器窗口缩放 |
| PC | 1280×720、1366×768、1920×1080；100/125/150/200% 缩放 |
| 内容 | 空数据、多页、长中文、长条码、长备注、权限减少、错误提示 |
| 滚动 | 页面顶/中/底、列表容器边界、sticky 切换、弹窗内部滚动 |
| 浏览器 | Windows Chrome/Edge、iPhone Safari、Android Chrome；仿真和真机分开记录 |

当前 dev.7 提供代表页面静态样稿；此矩阵是后续 dev.12 的整站验收要求，不能把样稿评审等同于真机验收。
